Featured project / Data Engineering + Search

Real-Time Search & Data Pipeline

A search integration architecture that connects Microsoft SQL Server data to Typesense through Apache Kafka. A FastAPI proxy provides a controlled interface for frontend search requests, using JWT-based authentication to protect access to the search service.

SQL ServerApache KafkaKafka ConnectTypesensePythonFastAPIJWTVue / React

Architecture & responsibilities

  • Connect source data in SQL Server to a search-oriented data flow using Kafka source and sink connectors.
  • Use Kafka topics to decouple database updates from downstream search indexing.
  • Organize searchable records in Typesense collections and support multi-collection search.
  • Build a FastAPI proxy layer for authenticated search requests without exposing administrative search credentials in the browser.
  • Integrate frontend search interfaces with token-based access, debounced queries, and user-scoped filters.

Design considerations

  • Decoupling: Kafka separates source systems from search indexing.
  • Resilience: queued events help tolerate temporary downstream interruptions, subject to connector and retention configuration.
  • Access control: authenticated API requests and user-specific filtering support safer search experiences.
